## Arobi work in this fork

Arobi Technology Alliance, Inc. is adding the **Arobi Familiar Memory Plane (FMP)**: an assurance/governance layer for persistent familiar memory, including versioned Arobi-specific contracts, provenance, mutation evidence, continuity state, controlled forgetting, context-use receipts, integration with Immaculate authority, JAWS Flight Deck projection, Crucible/ArobiMemBench gates, and optional evidence commitments.

The key Arobi invariant is:

> Memory may inform or describe authority. Memory cannot mint, carry, amplify, or satisfy current execution authority.

A remembered approval, permission, role, policy, or instruction remains context. Protected consequential execution must re-establish current authority through Arobi's authority plane.
